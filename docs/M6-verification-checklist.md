## A. 최근 수정 4종 (핵심 회귀) 🔴

가장 중요 — 다 실촬영 검증 대기였던 것들.

**A1. 음성 겹침 방지**

- [ ] 세트 시작 시 `form_intro`(긴 자세 설명) 재생 중에 **바로 스쿼트 시작** → 앞 음성이 **안 끝났는데 교정 음성이 겹쳐 나오지 않는지**. 앞 음성이 끝나야 다음이 나오면 OK
- [ ] 교정이 연달아 필요한 상황에서도 두 음성이 동시에 안 겹치는지

**A2. 막판 5회 카운트다운**

- [ ] 15회 세트에서 **10회 지나면(남은 5)** → "다섯 개 남았어요!" → "넷!" → "셋!" → "둘!" → "마지막 하나!" 순으로 카운트되는지
- [ ] 카운트 구간에선 교정/동기부여 대신 **카운트가 우선**으로 나오는지

**A3. 세트 끝내기 버튼**

- [ ] (a) 세트 도중 누르면 **지연 없이 즉시** 요약 화면으로 가는지
- [ ] (b) **1세트 15회 완주 → 2세트 자동 전환 직후(2세트 0회)** "세트 끝내기" → 요약에 **직전 1세트 값(15회)** 이 뜨는지 (**0회 아님** = 이번에 고친 버그)
- [ ] (c) 2세트에서 몇 개 하고 끝내면 **그 개수**가 요약에 뜨는지

**A4. 깊이 오탐**

- [ ] **정상 깊이 스쿼트**(허벅지 수평 근처)에서 "더 깊게/무릎 더 굽혀" **오탐이 안 나오는지**
- [ ] 콘솔 `[depth-debug] calib`: `stored`(p90) **175~178**, `[depth-debug] rep`: 정상 깊이일 때 `shallow:false`
  - `stored`가 <168이면 → 깊이가 아니라 **카메라 배치(측면각·거리)** 문제로 의심

## D. 코칭 루프 품질 (조건 바꿔가며) — M6 본인 단독

각 조건에서 ① 반복 카운트 정확도(놓침/중복) ② 오탐(정상인데 지적)/미탐(틀렸는데 통과) 체감 ③ "봐주는 느낌" 주관 점수(1~5) 기록.
