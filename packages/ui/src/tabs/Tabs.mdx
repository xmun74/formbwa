# Tabs

**상호작용 합성** — Context로 활성 탭을 공유(`"use client"`), **닷 노테이션** API.
ARIA tabs 패턴(role tablist/tab/tabpanel, **roving tabindex + 화살표/Home/End 키**).

## 사용법

uncontrolled(`defaultValue`) 또는 controlled(`value`/`onValueChange`). **클라이언트 트리 안에서** 소비.

```tsx
"use client";
import { Tabs } from "@repo/ui";

<Tabs defaultValue="squat">
  <Tabs.List>
    <Tabs.Trigger value="squat">스쿼트</Tabs.Trigger>
    <Tabs.Trigger value="pushup">푸시업</Tabs.Trigger>
  </Tabs.List>
  <Tabs.Content value="squat">하체 기본…</Tabs.Content>
  <Tabs.Content value="pushup">상체…</Tabs.Content>
</Tabs>;
```
