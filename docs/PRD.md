# PRD — 폼봐 (formbwa) · AI 맨몸운동 코치

> 기획명세서. 무엇을, 왜, 누구에게 만드는지 정의한다.
>
> 관련 문서: 구현 방법은 [TRD-FE.md](./TRD-FE.md)·[TRD-BE.md](./TRD-BE.md), 작업 분해·진행 상황은 [TASKS.md](./TASKS.md) 참조. 이 문서의 기능 ID(F1-1 등)는 각 문서에서 그대로 인용된다.

## 1. 제품 개요

웹캠으로 사용자의 맨몸운동 자세를 실시간 인식하고, 개성 있는 캐릭터 코치가 운동하는 바로 그 순간 짧은 음성으로 교정·격려해주는 서비스.

- 비전: "움직임을 보고 코칭하는 엔진"을 만들어 맨몸운동 → 요가/필라테스 → (제휴 후) 춤으로 확장
- 한 줄 경험 목표: **"옆에서 누가 진짜 봐주는 느낌인데?"**
- 초기 시장/언어: **한국어 단일** (캐릭터 콘셉·멘트·UI 모두 한국어 전용. 글로벌은 국내 검증 후)
- 주 사용 환경 (1단계): **데스크톱/노트북 브라우저 우선.** 모바일 브라우저는 동작하되 최적화 후순위 (3단계에서 격상)

## 2. 문제 정의

- 개인 PT는 회당 5~10만원으로 비싸고, 시간·장소 제약이 크다
- 혼자 홈트하면 자세가 맞는지 알 수 없어 부상 위험이 있고, 재미가 없어 금방 포기한다
- 기존 피트니스 앱 대부분은 운동 "전후"(계획 추천, 기록)에 집중하고, 운동 "순간"에는 영상만 틀어준다

## 3. 타깃 사용자

| 우선순위 | 대상 | 니즈 |
|---|---|---|
| 1차 | 홈트 입문자 (20~30대, 헬스장 부담) | 자세 불안 해소, 재미, 습관 형성 |
| 2차 | 헬스장 초보 | 기본 동작(스쿼트 등) 자세 학습 |
| 3차 (확장) | 요가/필라테스 홈수련자 | 정적 자세 정확도 확인 |

## 4. 핵심 사용자 시나리오 (1단계)

1. 링크 접속 → 캐릭터 코치 선택 (2종)
2. 카메라 권한 허용 → 화면 안내에 따라 몸 전체가 보이게 배치 (측면 45° 권장 가이드)
3. 기립 자세로 캘리브레이션 (약 3초)
4. 스쿼트 시작 → 실시간 카운트 + 짧은 음성 피드백
   - "무릎 조금 더 굽혀요" / "허리 세워요" / "좋아요, 방금 자세 괜찮았어요" / "하나만 더!"
5. 세트 종료 → 요약 화면: 횟수, 자세 품질 비율, 가장 많이 지적된 포인트 1~2개, 캐릭터 톤의 총평 한 단락
6. (2단계~) 로그인 시 기록 저장, 누적 대시보드 확인

## 5. 기능 요구사항 (단계별)

### 1단계 — 실시간 코칭 루프 (로그인/저장 없음)

| ID | 기능 | 필수 여부 |
|---|---|---|
| F1-1 | 스쿼트 자세 인식 및 반복 카운트 | 필수 |
| F1-2 | 무릎/허리/상체 각도 기반 실시간 판정 | 필수 |
| F1-3 | 판정 이벤트에 대한 캐릭터 음성 피드백 (짧게, 쿨다운 있음) | 필수 |
| F1-4 | 코치 캐릭터 2종 선택 | 필수 |
| F1-5 | 카메라 배치 가이드 + 기립 캘리브레이션 | 필수 |
| F1-6 | 세트 종료 요약 화면 (로컬 표시) | 필수 |
| F1-7 | 랜드마크/가이드 시각 오버레이 | 권장 |

### 2단계 — 계정, 기록, 리포트

| ID | 기능 |
|---|---|
| F2-1 | 구글 로그인 (게스트는 운동 무제한 — 기록 저장 시에만 로그인 요구) |
| F2-2 | 세트 기록 저장 (수치 데이터만, 영상 저장 안 함) |
| F2-3 | 세트 직후 AI 리포트: 캐릭터 톤 총평 자동 생성 |

### 3단계 — 리텐션

| ID | 기능 |
|---|---|
| F3-1 | 누적 대시보드: 주간 운동 횟수, 총 스쿼트 수, 평균 깊이 추이 |
| F3-2 | 스트릭(연속 일수) + 캘린더 히트맵 |
| F3-3 | 운동 종목 추가 (푸시업, 런지) |
| F3-4 | 캐릭터 추가 (츤데레 코치, 군대 조교 등 후보) + 모바일 브라우저 최적화 격상 |
| F3-5 | 세트 리포트 공유 페이지 — 공유 링크 + OG 미리보기 (오운완 인증 → 신규 유입 바이럴 루프) |

### 4단계 — 앱 출시 및 수익화

| ID | 기능 |
|---|---|
| F4-1 | React Native 앱 스토어 출시 (Capacitor 단계 생략, RN 직행) |
| F4-2 | 푸시 알림 (운동 리마인드, 스트릭 위기 알림) |
| F4-3 | 구독 결제 (웹 결제 우선, 스토어 수수료 회피) |

### 확장 로드맵 (검증 후)

요가/필라테스(정적 자세, 판정 난도 낮음) → 춤(안무가/기획사 제휴 확보 후에만. 무단 진행 시 저작권 리스크 — '샤이보이' 판례)

## 6. 캐릭터 정의 (초기 2종, 한국어 전용)

| 캐릭터 | 톤 | 예시 멘트 |
|---|---|---|
| 열정 PT쌤 | 하이텐션, 응원 위주 | "좋아요!! 딱 하나만 더!!" |
| 부산 사투리 쌤 | 구수한 잔소리 | "무릎 그래 펴면 안 된다카이~" |

3단계 추가 후보: 츤데레 코치, 군대 조교. 사투리 캐릭터는 TTS 사투리 표현 품질 검증(1단계 초기)을 통과해야 확정.

멘트 원칙: 한 번에 한 가지만 지적, 3초 이내 길이, 같은 지적 연속 반복 금지, 칭찬:지적 비율 최소 1:2 유지.

## 7. 비범위 (하지 않는 것)

- 영상 저장·서버 전송 (리플레이 기능 포함) — 개인정보 리스크 등급이 달라짐
- 얼굴 인식·신원 확인 — 생체인식정보(민감정보) 해당 소지 차단
- 재활·의료 목적 코칭 — 의료기기 규제 영역
- K-pop 안무 콘텐츠 — 제휴 전까지 금지
- 웨어러블 연동, 식단 관리

## 8. 성공 지표

| 단계 | 핵심 지표 | 목표 |
|---|---|---|
| 1단계 | 세트 완료율 (시작 대비 종료) | 60%+ |
| 1단계 | 체험 후 정성 반응 ("봐주는 느낌" 언급) | 인터뷰 10명 중 6명+ |
| 2~3단계 | D7 리텐션 | 20%+ |
| 3단계 | 주 2회 이상 운동 사용자 비율 | 30%+ |
| 4단계 | 무료→유료 전환율 | 3~5% |

정확도가 아니라 **재방문**이 최우선 지표. 1단계에서 "다음 날 또 오는가"가 검증 대상이다.

## 9. 수익화

- 모델: Freemium 구독 — **경계는 "운동은 무료, 데이터는 유료"로 확정**
  - 무료: 전체 운동 + 전체 캐릭터 + 세트 직후 요약 (핵심 경험은 막지 않아 리텐션·바이럴 우선)
  - 유료: AI 캐릭터 리포트, 누적 대시보드, 추이 차트, 스트릭 (데이터가 쌓인 사용자일수록 전환 동기 강화)
- 가격: 미정. 월 1만원대 가설(경쟁가 검증됨)만 두고 4단계 직전 설문/테스트로 확정
- 가격 앵커: PT 회당 5~10만원 vs 월 구독 커피 2~3잔 값
- 유입 전략: 쇼츠(캐릭터 코칭 장면) → 링크 → 설치 없이 즉시 체험 → 계정 생성
- B2C 부진 시 피벗 여지: 기업 복지/보험사 웰니스 B2B2C

| 리텐션 저조 (피트니스 앱 공통) | 스트릭·리포트·캐릭터 애착 설계. 1단계에서 재방문 미검증 시 기능 확장 중단하고 코칭 경험 개선에 집중 |
| 경쟁사(프롬 등) 기능 유사 | 기능 경쟁 회피, 캐릭터·콘텐츠·바이럴 중심 차별화 유지 |
| 춤 확장 시 저작권 | 제휴 없이는 진행하지 않음 (원칙 고정) |
